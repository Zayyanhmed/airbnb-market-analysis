# Airbnb Market Analysis & Interactive Tableau Dashboard

## Project Overview

This project analyses Airbnb listing and calendar data to explore accommodation pricing, geographic variation, revenue trends and the relationship between bedroom count and average listing price.

The objective is to turn accommodation data into meaningful visualisations that help users explore market patterns and compare prices across different locations.

## Business Questions

This project explores the following questions:

1. How does the revenue-related metric change over time?
2. How do average Airbnb prices vary across ZIP codes?
3. How does average price differ by bedroom count?
4. Which geographic areas have higher average listing prices?

## Methodology & Limitations

The dashboard presents descriptive analysis of Airbnb listing and calendar data.

Revenue-related measures should be interpreted according to their calculation and should not automatically be treated as actual booking revenue.

Average prices can vary depending on listing characteristics, sample sizes and the locations represented in the dataset.
